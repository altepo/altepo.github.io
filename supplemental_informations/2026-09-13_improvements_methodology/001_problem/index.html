## Problem demonstration

The task consist in classifying images. 

A test dataset containing 1000 images and labels was constructed.
The dataset contains 500 true positives and 500 true negatives.

The confusion matrix is:

Actual condition | Predicted Positive | Predicted Negative
| :--- | :---: | :---: |
Real Positive | 360 | 140 |  
Real Negative |  107 | 450 |

The Recall is: 360/500 = 72%.
The Precision is: 360/(360+107) = 77%.

(Add confidence as well)

The targeted recall is 90%. There is still room for improvement.

The test dataset was randomly sampled and span the production over a month.

A test was carried and showed that the labeling process is 98% accurate.
